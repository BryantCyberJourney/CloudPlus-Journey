# Security Best Practices

## Use Strong Passwords
- Create long and complex passwords
- Avoid reusing passwords across accounts
- Use password managers when possible

---

## Enable Multi-Factor Authentication (MFA)
MFA adds an additional layer of security beyond passwords.

Examples:
- Authentication apps
- Security keys
- Biometrics

---

## Keep Systems Updated
Regular updates help patch security vulnerabilities and reduce risk.

Examples:
- Operating system updates
- Software updates
- Firmware updates

---

## Practice Least Privilege
Users should only have the minimum access necessary to perform their job responsibilities.

---

## Backup Important Data
Regular backups help organizations recover from:
- Ransomware attacks
- Hardware failures
- Accidental deletion
- Data corruption

---

## Be Aware of Phishing Attacks
Always verify:
- Email senders
- Links
- Attachments
- Login pages

---

## Use Secure Networks
- Avoid unsecured public Wi-Fi when possible
- Use VPNs for secure remote connections

---

## Monitor Systems and Logs
Regular monitoring helps identify suspicious activity early.

Examples:
- Failed login attempts
- Unusual network traffic
- Unauthorized access attempts
