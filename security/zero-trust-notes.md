# Zero Trust Security Model

## What is Zero Trust?
Zero Trust is a cybersecurity model based on the principle:

"Never trust, always verify."

Users and devices must continuously verify identity and authorization before gaining access to systems and data.

---

## Core Principles of Zero Trust
- Verify every user and device
- Enforce least privilege access
- Continuously monitor activity
- Assume breaches can occur
- Limit lateral movement within networks

---

## Key Zero Trust Components
- Multi-factor authentication (MFA)
- Identity and Access Management (IAM)
- Network segmentation
- Endpoint security
- Continuous monitoring

---

## Benefits of Zero Trust
- Reduces unauthorized access
- Improves visibility
- Limits attack spread
- Strengthens security posture

---

## Zero Trust Best Practices
- Enable MFA
- Review permissions regularly
- Segment networks
- Monitor login activity
- Use least privilege principles
