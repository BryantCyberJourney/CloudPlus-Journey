# Common Networking Ports

## Port 20/21 - FTP (File Transfer Protocol)
Used for transferring files between systems.

Security Concern:
FTP is not encrypted.

---

## Port 22 - SSH (Secure Shell)
Used for secure remote access to systems.

Common Use:
Secure server administration.

---

## Port 23 - Telnet
Used for remote command-line access.

Security Concern:
Telnet is not encrypted and is considered insecure.

---

## Port 25 - SMTP (Simple Mail Transfer Protocol)
Used for sending email messages.

---

## Port 53 - DNS (Domain Name System)
Used for translating domain names into IP addresses.

Example:
google.com → IP address

---

## Port 67/68 - DHCP (Dynamic Host Configuration Protocol)
Used for automatic IP address assignment.

---

## Port 80 - HTTP
Used for unencrypted web traffic.

---

## Port 110 - POP3
Used for receiving email messages.

---

## Port 143 - IMAP
Used for receiving and managing email messages.

---

## Port 389 - LDAP
Used for directory services and authentication.

---

## Port 443 - HTTPS
Used for encrypted secure web traffic using SSL/TLS.

---

## Port 3389 - RDP (Remote Desktop Protocol)
Used for remote desktop access to Windows systems.

Security Concern:
Frequently targeted by attackers if improperly secured.

---

# Port Security Notes
- Disable unused ports
- Use firewalls to restrict access
- Monitor for unusual traffic
- Use encrypted protocols whenever possible
