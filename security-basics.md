# Security Basics

## CIA Triad

### Confidentiality
Protecting sensitive information from unauthorized access.

Examples:
- Encryption
- Access controls
- Multi-factor authentication (MFA)

---

### Integrity
Ensuring data remains accurate and is not improperly modified.

Examples:
- Hashing
- File permissions
- Version control

---

### Availability
Ensuring systems, applications, and data remain accessible when needed.

Examples:
- Backups
- Redundancy
- Disaster recovery planning

---

## Authentication
The process of verifying the identity of a user or system.

Examples:
- Passwords
- Biometrics
- Security tokens

---

## Authorization
Determining what resources or systems a user is allowed to access after authentication.

---

## Least Privilege
Users should only have the minimum level of access required to perform their job responsibilities.

---

## Multi-Factor Authentication (MFA)
A security process requiring multiple forms of verification.

Examples:
- Password + authentication app
- Password + fingerprint
- Password + text message code

---

## Phishing
A social engineering attack designed to trick users into revealing sensitive information.

Common warning signs:
- Urgent language
- Suspicious links
- Fake login pages
- Unknown senders
- Requests for passwords or financial information

---

## Malware
Software created to damage, disrupt, or gain unauthorized access to systems.

Examples:
- Viruses
- Worms
- Trojans
- Ransomware
- Spyware

---

## Firewall
A security device or software that monitors and filters incoming and outgoing network traffic based on security rules.

---

## Encryption
The process of converting data into unreadable code to protect confidentiality.

---

## Security Best Practices
- Use strong passwords
- Enable MFA
- Keep software updated
- Avoid suspicious links and attachments
- Perform regular backups
- Follow least privilege principles
