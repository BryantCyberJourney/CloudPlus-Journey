# Networking Basics

## IP Address
An IP address is a unique address assigned to a device on a network.

## DNS (Domain Name System)
DNS translates domain names into IP addresses so devices can locate websites and services.

Example:
google.com → IP address

## DHCP (Dynamic Host Configuration Protocol)
DHCP automatically assigns IP addresses and network settings to devices.

## Default Gateway
The default gateway allows devices on a local network to communicate with external networks such as the internet.

## VPN (Virtual Private Network)
A VPN creates a secure encrypted connection over the internet.

## Firewall
A firewall monitors and filters incoming and outgoing network traffic based on security rules.

## LAN (Local Area Network)
A LAN is a network covering a small geographic area such as a home, office, or building.

## WAN (Wide Area Network)
A WAN connects networks over large geographic distances.

## LDAP (Lightweight Directory Access Protocol)
LDAP is used for accessing and managing directory services.

## SMTP (Simple Mail Transfer Protocol)
SMTP is used for sending email messages.

## HTTPS
HTTPS encrypts web traffic using SSL/TLS for secure communication.

## Ping
Ping is a troubleshooting tool used to test connectivity between devices.

## Packet Loss
Packet loss occurs when network packets fail to reach their destination.

## Network Troubleshooting Steps
- Verify IP configuration
- Check network cables or Wi-Fi connection
- Test DNS resolution
- Ping the default gateway
- Review firewall settings
- Restart networking devices if necessary
