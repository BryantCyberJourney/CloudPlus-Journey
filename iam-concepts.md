# Identity and Access Management (IAM)

## What is IAM?
Identity and Access Management (IAM) is the process of controlling who has access to systems, applications, and data.

IAM helps organizations:
- Manage user identities
- Control permissions
- Protect sensitive information
- Enforce security policies

---

## Authentication
Authentication verifies a user's identity.

Examples:
- Passwords
- Biometrics
- MFA
- Smart cards

---

## Authorization
Authorization determines what resources a user is allowed to access after authentication.

Example:
A user may have access to email but not administrative systems.

---

## Principle of Least Privilege
Users should only receive the minimum permissions necessary to perform their job responsibilities.

Benefits:
- Reduces attack surface
- Limits accidental changes
- Improves security

---

## Multi-Factor Authentication (MFA)
MFA requires multiple forms of verification before access is granted.

Examples:
- Password + phone app
- Password + fingerprint
- Password + security key

---

## Role-Based Access Control (RBAC)
Access permissions are assigned based on job roles instead of individual users.

Example:
- Helpdesk technician
- Network administrator
- Security analyst

---

## Account Management Best Practices
- Disable unused accounts
- Review permissions regularly
- Use strong passwords
- Enable MFA
- Monitor login activity
